# altgu-bot

Telegram-бот для личного кабинета АлтГУ: показывает учебный план, сообщения и расписание,
а по запросу отвечает на вопросы по расписанию с помощью ИИ.

Проект начинался как дипломная работа колледжа (2025). Эта версия — переработанная:
современные библиотеки, безопасное хранение секретов и паролей, тесты.

## Возможности

| Команда / кнопка | Что делает |
|---|---|
| `/login`, «Войти в аккаунт» | вход в личный кабинет (логин и пароль вводятся в чате) |
| `/plan`, «Мой учебный план» | учебный план **текущего курса** по семестрам: часы, контроль, оценка, дата; кнопки «1 курс / 2 курс / 3 курс» под таблицей (или `/plan 1`, `/plan 2`, `/plan 3`) |
| `/messages`, «Сообщения» | последние 10 сообщений |
| `/timetable`, «Моё расписание» | расписание на неделю |
| «Бот: …» или `/ask …` | вопрос по расписанию («Бот: что у меня завтра?») |
| `/logout`, «Выйти» | выход, сессия удаляется |

## Быстрый старт

Нужны Python 3.10+ и Google Chrome (он используется только для входа и как запасной вариант).

```bash
python -m venv venv
venv\Scripts\activate          # Windows;  macOS/Linux: source venv/bin/activate
pip install -r requirements.txt

copy .env.example .env         # macOS/Linux: cp .env.example .env
# впишите BOT_TOKEN (и при желании OPENAI_API_KEY) в .env

python -m altgu_bot
```

Токен бота выдаёт @BotFather. **Никогда не коммитьте `.env` и не вставляйте токены в код.**

## Публикация на GitHub без утечек

В `.gitignore` уже исключены `.env`, окружение `venv`, логи, архивы и ключи. Дополнительно есть скрипт
`scripts/check_secrets.py`, который перед публикацией ищет токены Telegram, ключи OpenAI/Google/GitHub,
приватные ключи, значения паролей в коде, сохранённые HTML-страницы и ваши «запретные слова».
Найденный секрет он печатает только частично.

```bash
git init
python scripts/check_secrets.py --install-hook   # проверка будет запускаться перед каждым коммитом
python scripts/check_secrets.py                  # ручная проверка всего проекта
git add .
git status                                       # убедитесь, что в списке нет .env и venv
git commit -m "Первый коммит"
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

173 теста, браузер, Telegram и интернет не нужны:

- `test_parsers.py` — разбор HTML (учебный план, сообщения, расписание), в т.ч. пустые и «сломанные» страницы;
- `test_formatters.py` — экранирование HTML, разбиение длинных таблиц под лимит Telegram (4096 символов);
- `test_sessions.py` — время жизни сессии и блокировка перебора пароля;
- `test_config_and_portal.py` — проверка настроек, определение страницы входа;
- `test_check_secrets.py` — поиск секретов, запрещённые файлы, настоящий git и блокировка коммита хуком;
- `test_handlers.py` — сквозные сценарии диалога на настоящих хендлерах с поддельными Telegram и порталом:
  вход, удаление сообщения с паролем, блокировка после неудачных попыток, истёкшая сессия, ИИ.

## Структура

```
altgu_bot/
  config.py      настройки из .env / переменных окружения
  portal.py      вход (Selenium) и загрузка страниц (HTTP с запасным браузером)
  parsers.py     HTML -> данные (чистые функции)
  formatters.py  данные -> текст для Telegram, разбиение на сообщения
  sessions.py    хранение сессий с TTL, защита от перебора пароля
  ai.py          ИИ-помощник (OpenAI)
  handlers.py    диалог с пользователем (aiogram 3)
  __main__.py    запуск
scripts/         check_secrets.py — проверка секретов перед публикацией
tests/           тесты и сохранённые HTML-страницы (tests/fixtures)
```

## Что изменилось по сравнению с дипломной версией

| Было | Стало |
|---|---|
| Токены Telegram и OpenAI прямо в коде | всё в `.env`, ошибка с подсказкой, если токена нет |
| Пароль оставался в истории чата | сообщение с паролем удаляется сразу; пароль нигде не хранится |
| Cookie хранились вечно | сессия живёт `SESSION_TTL` секунд, есть `/logout` |
| Пароль можно было подбирать бесконечно | не более 3 неудачных входов за 10 минут |
| Новый Chrome на каждый запрос + `sleep(3)` | быстрый HTTP с cookie; браузер — только для входа и как запасной вариант; ожидание нужной таблицы вместо фиксированной паузы |
| Много пользователей = много Chrome сразу | не более `MAX_BROWSERS` одновременно |
| aiogram 2 (`contrib`), устаревшая библиотека | aiogram 3 |
| `openai.ChatCompletion` (openai < 1.0) | `AsyncOpenAI`, таймаут, обработка ошибок, дата и день недели в запросе |
| Markdown: падал на символах `*` `_` в данных | HTML-режим с экранированием |
| Длинный учебный план мог не отправиться (лимит Telegram) | автоматически делится на сообщения, шапка таблицы в каждом |
| Предметы хранились в словаре по названию (дубликаты терялись) | список, ничего не теряется |
| Код парсеров и бота в одном классе, без тестов | модули + 173 теста |

## Ограничения и честные оговорки

- **Как кабинет отдаёт учебный план.** Таблицы плана подгружаются на странице скриптом, причём сразу все курсы одним ответом
  (`POST /ajax/`), а показывается выбранный. Поэтому план всегда берётся через браузер, а бот сам выбирает текущий курс
  (по вкладке, открытой на странице, а если её нет — по учебному году). В вёрстке кабинета также есть ошибка (сломанный тег `<tbody`),
  из-за которой теряется заголовок первого семестра; парсер её учитывает.
- **Селекторы портала** (`decanat-student-plan`, `timetable-week`, `list_table`, поля входа)
  взяты из дипломной версии. Если вёрстка `lk.asu.ru` с тех пор изменилась, парсеры придётся поправить.
- **HTML-файлы в `tests/fixtures` — синтетические**, собраны по этим селекторам, а не сохранены с настоящего портала.
  Лучше заменить их реальными страницами (предварительно убрав личные данные) — тогда тесты будут проверять настоящую вёрстку.
- Сетевая часть (`portal.py`) и вызов OpenAI проверены только через подмену в тестах, не вживую.
- Если режим `auto` по HTTP не получает нужную страницу, он сам откатывается на браузер. Можно зафиксировать
  `FETCH_MODE=selenium` (медленнее, но как в дипломной версии).
- Бот предназначен для работы **со своим аккаунтом**. Проверьте правила университета, прежде чем давать им
  пользоваться другим студентам: их пароли будут проходить через ваш сервер.
- **Бесплатный ИИ-помощник:** получите ключ Google Gemini на aistudio.google.com/apikey и впишите его в `.env`
  как `GEMINI_API_KEY` — адрес сервера и модель подставятся сами. Бесплатные лимиты Google могут меняться.
  Вместо Gemini можно использовать OpenAI (`OPENAI_API_KEY`) или локальный Ollama (см. `.env.example`).
- **Приватность ИИ-помощника:** при вопросе «Бот: …» расписание отправляется в OpenAI. Не нужно — оставьте `OPENAI_API_KEY` пустым.
